# 扑克牌双重 N-back 游戏设计规格

## 目标

在 `poker-n-back/` 中新增一个可直接双击 HTML 打开的离线网页游戏。玩家依次观看扑克牌，从第 N+1 张开始判断当前牌与前第 N 张牌的花色和点数关系；游戏支持参数配置、逐题限时反馈、整局统计、浅色与黑暗模式。

## 文件结构

- `poker-n-back/poker-n-back.html`：设置、训练与结果三个页面状态的语义化 HTML 结构。
- `poker-n-back/styles.css`：专注训练视觉风格、响应式布局、浅色和黑暗模式、动画降级。
- `poker-n-back/game-core.js`：参数校验、随机发牌、关系判断、正确答案集合、统计与记录生成。
- `poker-n-back/app.js`：页面状态切换、倒计时、鼠标和键盘输入、防重复提交、反馈与结果渲染。
- `poker-n-back/game-core.test.js`：使用 Node 内置测试工具验证所有核心规则。

所有浏览器脚本使用传统 `<script>` 方式加载，确保页面在 `file://` 环境中可直接运行，不需要服务器、构建工具、第三方包或网络连接。核心逻辑同时通过 CommonJS 导出供 Node 测试使用。

## 参数与发牌

- 默认总牌数为 10，默认 N 为 2。
- 总牌数必须是 2–100 之间的整数。
- N 必须是 1 到“总牌数 − 1”之间的整数。
- 输入非法时，在对应字段附近显示明确提示并禁止开始游戏。
- 每张牌从 52 种标准牌面中独立随机生成，允许重复出现。花色为黑桃、红桃、梅花、方块，点数为 A、2–10、J、Q、K。

允许重复是必要规则：当当前牌和对比牌完全相同时，花色与点数都相同，选择 A 或 B 均判定为正确。

## 游戏流程

页面有三个互斥状态：开始设置、训练中、本局结果。

开始设置状态展示总牌数和 N 的输入框、规则摘要及“开始训练”按钮。开始后一次性生成本局全部牌，并进入训练状态。

训练状态按顺序每 4 秒展示一张牌：

1. 前 N 张属于记忆阶段，只展示牌面、进度和“记忆阶段”提示，A/B/C 按钮不可用。
2. 从第 N+1 张开始，当前牌与索引减 N 的牌比较，显示 4 秒倒计时并启用判断按钮。
3. 玩家可点击按钮或按键盘 A、B、C 作答。
4. 每道判断仅接受第一次有效提交，快速连点、按键重复和过期计时回调不会重复记分或跳过牌。
5. 回答正确后显示短暂正确状态并进入下一张。
6. 回答错误或 4 秒内未回答时，停止本题倒计时，显示正确答案 1.2 秒后进入下一张。完全相同的牌显示“A 花色相同或 B 点数相同”。
7. 最后一张反馈完成后进入结果状态。

判断关系如下：

- A：花色相同。
- B：点数相同。
- C：花色与点数都不相同。
- 花色和点数都相同时，A、B 均为正确答案。

## 计时模型

每张牌开始展示时创建唯一的回合标识和截止时间。界面根据截止时间更新剩余时间，避免仅依靠固定次数递减造成累计偏差。切换牌、提交答案和结束游戏时清除旧计时器；所有回调在改变状态前检查回合标识，防止旧回调作用于新牌。

记忆牌展示 4 秒后自动切换。判断牌在 4 秒截止时记录为超时。错误或超时的 1.2 秒反馈阶段不计入下一张牌的时间。

## 统计与记录

判断题总数固定为“总牌数 − N”。正确率计算公式为：

`正确判断数 ÷ 判断题总数 × 100%`

结果页显示百分比、正确题数、判断题总数，并记录全部牌：

- 前 N 张标记为“记忆牌”。
- 后续每张记录序号、当前牌、对比牌、玩家选择、正确答案和结果。
- 超时题的玩家选择显示“未作答”。
- 完全相同的牌的正确答案显示“A 或 B”。

“再来一局”保留当前参数并重新随机发牌；“修改设置”返回设置状态并保留当前参数值。

## 视觉与响应式设计

采用已确认的“专注训练”方向：低刺激的自然绿色、充足留白、明确的卡片层级和清晰的进度信息。训练状态将牌面作为唯一视觉焦点，进度和剩余时间置于上方，三个判断按钮置于下方。

页面使用 CSS 自定义属性管理颜色，并通过 `prefers-color-scheme: dark` 自动切换黑暗模式。两种模式均保证正文、辅助文字、边框、按钮、成功和错误反馈具有足够对比度。扑克牌保持浅色纸面，以红色显示红桃和方块、深色显示黑桃和梅花。

桌面端判断按钮横向排列；窄屏时自动变为适合触控的布局。结果表在窄屏允许区域内横向滚动，不压缩到难以阅读。页面不依赖固定高度，并适配手机安全区域。

## 无障碍与交互细节

- 所有输入框和按钮使用可见文本标签。
- 键盘 A/B/C 与三个判断按钮一一对应，仅在判断阶段生效。
- 使用清晰的 `:focus-visible` 样式。
- 当前阶段、回答反馈和超时反馈通过 `aria-live` 播报。
- 不仅依赖颜色表达正确或错误，同时显示文字和图标语义。
- 使用 `prefers-reduced-motion` 减少翻牌、缩放和状态切换动画。
- 禁用按钮保持可辨识，但不会获得交互响应。

## 测试与验收

自动测试覆盖：

- 默认参数和合法边界。
- 非整数、越界总牌数、N 小于 1、N 不小于总牌数。
- 仅花色相同、仅点数相同、二者都相同、二者都不相同。
- 完全相同牌接受 A 或 B，拒绝 C。
- 正确率和全牌记录生成，包括记忆牌、错误题和超时题。

浏览器验收覆盖：

- 默认参数完成一整局。
- 修改总牌数和 N 后完成一整局。
- 错误答案显示正确答案 1.2 秒。
- 判断牌 4 秒未回答后记为超时并显示正确答案。
- 鼠标点击和 A/B/C 键盘输入均有效且不会重复提交。
- 浅色模式、黑暗模式和窄屏布局均可阅读和操作。
- 结果统计与逐牌记录和本局实际过程一致。
